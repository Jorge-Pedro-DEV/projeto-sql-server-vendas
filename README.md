# Projeto SQL Server - EmpresaA

Projeto desenvolvido para praticar consultas SQL utilizando Microsoft SQL Server.

# Banco de Dados

# O banco contém informações sobre:
- Clientes
- Vendedores
- Vendas

- Consultar dados
- Aplicar filtros
- Ordenar resultados
- Realizar contagens
- Desenvolver análises comerciais

# Tecnologias:
- Microsoft SQL Server
- SQL Server Management Studio
- Git
- GitHub
